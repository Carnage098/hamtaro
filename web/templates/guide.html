PARCOURS JOUEUR

Participer à un tournoi

1

Identifier le bon tournoi

Hamtaro peut gérer plusieurs tournois en même temps. Commence par consulter le contexte et le statut afin d'éviter d'agir sur le mauvais tournoi.

{{ command_chip("/tournament_context") }} {{ command_chip("/tournament_status") }}
2

S'inscrire

Utilise la commande d'inscription pendant que les inscriptions sont ouvertes. Renseigne correctement ton deck et le format demandé. Ton inscription confirme ta disponibilité : il n'y a pas de check-in séparé.

{{ command_chip("/register") }}
3

Trouver son prochain match

Dès qu'un match est disponible, consulte ton adversaire, la ronde et la table. Le bracket ou le classement suisse permettent de suivre l'avancement général.

{{ command_chip("/nextmatch") }} {{ command_chip("/bracket") }} {{ command_chip("/match_center") }}
4

Jouer puis signaler le résultat

Après le duel, indique le vainqueur et le score exact. Le résultat n'est définitif qu'après validation du staff. Ne renvoie pas plusieurs fois le même résultat.

{{ command_chip("/report_result") }}
5

Suivre sa progression

Consulte ton historique, ton profil et tes performances par deck. Les données publiques du site viennent des résultats validés par le staff.

{{ command_chip("/profile") }} {{ command_chip("/match_history") }} {{ command_chip("/deck_stats") }}

STAFF ET MODÉRATION

Faire fonctionner le tournoi

A

Avant le lancement

  • Vérifier le format, le type et le nombre de joueurs.
  • Contrôler les inscriptions et les decks renseignés.
  • Vérifier le contexte du tournoi sélectionné.
  • Prévisualiser les rendus graphiques si nécessaire.
{{ command_chip("/tournament_status") }} {{ command_chip("/tournament_context") }} {{ command_chip("/graphics_preview") }}
B

Pendant les matchs

  • Consulter les résultats en attente.
  • Comparer le score aux informations des deux joueurs.
  • Approuver le résultat correct.
  • Refuser un résultat erroné en donnant une raison claire.
{{ command_chip("/pending_results") }} {{ command_chip("/approve_result") }} {{ command_chip("/reject_result") }}
C

Entre deux rondes

  • Vérifier qu'aucun match n'est encore bloqué.
  • Valider tous les résultats nécessaires.
  • Générer la ronde suivante ou faire avancer le bracket.
  • Publier l'image actualisée pour la communauté.
{{ command_chip("/tournament_progression") }} {{ command_chip("/bracket") }} {{ command_chip("/swiss_pair") }}
D

En cas de litige

  • Ne pas modifier le tournoi dans la précipitation.
  • Lire les logs et vérifier le dernier résultat validé.
  • Utiliser la réparation ou l'annulation uniquement après contrôle.
  • Informer les joueurs concernés de la décision.
{{ command_chip("/staff_logs") }} {{ command_chip("/repair") }} {{ command_chip("/tournament_undo") }}

ADMINISTRATION

Créer, clôturer et archiver

1. Créer et configurer

Définis le nom, le format, le type de tournoi et la capacité. Pour plusieurs tournois simultanés, vérifie toujours le code ou l'identifiant avant une action.

2. Ouvrir les inscriptions

Laisse les joueurs s'enregistrer, surveille la capacité et corrige les inscriptions problématiques avant le lancement.

3. Lancer le bon moteur

Utilise le bracket d'élimination directe ou le système suisse selon le type choisi. Ne mélange jamais les règles des deux.

4. Terminer proprement

Vérifie le champion, le classement final, les statistiques et l'image finale avant de clôturer le tournoi.

{{ command_chip("/end_tournament") }} {{ command_chip("/final_bracket") }} {{ command_chip("/tournament_export") }}
Attention : les commandes de réparation, d'annulation, de clôture et de suppression peuvent modifier l'historique. Lis toujours l'aperçu et les logs avant de confirmer.

RÈGLES TECHNIQUES

Suisse ou élimination directe

📊

Rondes suisses

  • Durée par défaut : 50 minutes par ronde.
  • Les rappels et le temps restant peuvent être affichés.
  • Le Double Loss est autorisé lorsque le staff le décide.
  • Une nouvelle ronde est appariée après validation des matchs.
{{ command_chip("/swiss_start") }} {{ command_chip("/swiss_pair") }} {{ command_chip("/swiss_report") }} {{ command_chip("/swiss_standings_image") }}
🏆

Élimination directe

  • Aucune limite automatique de 50 minutes.
  • Aucun Double Loss.
  • Un vainqueur doit obligatoirement être désigné.
  • Le gagnant avance vers le match suivant jusqu'à la finale.
{{ command_chip("/bracket") }} {{ command_chip("/bracket_full") }} {{ command_chip("/final_bracket") }}
